# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, and keep discussion about the work. Harassment, personal attacks, and publishing others' private information are not tolerated.

Report unacceptable behavior privately to the maintainers through a [GitHub security advisory](https://github.com/dushudou/dsh-web3/security/advisories/new) (it is private to maintainers) or by contacting a maintainer directly. Maintainers may remove comments, commits, or contributors that violate this code.
